## 📖 Sobre o projeto

O **Markdown Editor** é uma aplicação web desenvolvida para escrever e visualizar documentos Markdown diretamente no navegador.

A interface é dividida entre um **editor de texto** e uma área de **preview**, permitindo acompanhar em tempo real como o conteúdo será renderizado.

O projeto funciona como um pequeno editor de README e documentos `.md`, oferecendo recursos voltados principalmente para desenvolvedores que precisam criar ou editar documentação de forma rápida.

## ✨ Funcionalidades

### ✍️ Editor Markdown

Escreva conteúdos utilizando a sintaxe Markdown diretamente pelo navegador.

Exemplo:

```md id="yxw4oq"
# Meu projeto

Esse projeto foi desenvolvido utilizando **JavaScript**.

## Tecnologias

- HTML
- CSS
- JavaScript
```

---

### 👁️ Preview em tempo real

Enquanto o conteúdo é digitado no editor, o resultado é renderizado automaticamente na área de preview.

```text id="2b0tp8"
Editor Markdown
      │
      ▼
Texto digitado
      │
      ▼
Parser Markdown
      │
      ▼
HTML renderizado
      │
      ▼
Preview
```

---

### 📰 Formatação Markdown

O editor permite trabalhar com elementos comuns da linguagem Markdown, como:

* Títulos
* Parágrafos
* Negrito
* Itálico
* Listas
* Links
* Imagens
* Citações
* Blocos de código
* Código inline
* Separadores

---

### 💾 Documentos

O editor pode ser utilizado para criar e trabalhar com documentos Markdown diretamente pelo navegador.

Isso torna a aplicação útil para conteúdos como:

* README de projetos
* Documentação
* Anotações
* Tutoriais
* Textos técnicos
* Guias

---

### 📂 Importação de Markdown

Arquivos `.md` podem ser utilizados no editor para continuar trabalhando em documentos existentes.

---

### 📥 Exportação

O conteúdo criado pode ser salvo novamente como arquivo Markdown.

```text id="fr58y2"
documento.md
```

Isso permite editar um documento no navegador e depois utilizá-lo normalmente em projetos ou repositórios.

---

### 📋 Copiar HTML

O conteúdo renderizado pode ser convertido em HTML para reutilização em outros projetos ou páginas.

---

### 🖥️ Modo de visualização

O editor foi pensado para facilitar a escrita e a leitura, permitindo trabalhar com o conteúdo e seu resultado lado a lado.

## 🚀 Como executar

```bash id="e14kxa"
git clone https://github.com/EmanuelFHX/markdown-editor.git
```

### 2. Entre na pasta do projeto

```bash id="wb27fb"
cd markdown-editor
```

### 3. Execute a aplicação

Abra o arquivo `index.html` diretamente no navegador ou utilize um servidor local.

## 🎯 Objetivo

O objetivo do **Markdown Editor** é oferecer uma ferramenta simples e prática para criação de documentos Markdown.
